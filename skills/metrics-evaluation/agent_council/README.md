# Agent Council Records

This directory contains non-normative editorial history for maintainers.

## Exclusion Contract

- `SKILL.md` must not route to or reference this directory.
- Council records are not evaluation instructions and must not be loaded during normal skill use.
- Normative decisions must be implemented in `topics/`, `domains/`, or `references/`.
- Plugin manifests must not identify council files as skill entry points.
- Future reviews may consult these records only to understand prior debate and rejected alternatives.

The repository-level README defines `agent_council/` directories as internal editorial
records rather than required skill content. This local contract makes that boundary
explicit for `metrics-evaluation`.
