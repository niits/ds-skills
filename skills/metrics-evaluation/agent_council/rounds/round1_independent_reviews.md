# Round 1: Independent Reviews

## Statistical Validity Reviewer

The reviewer challenged the conclusion taxonomy, prevalence-based AUC wording,
categorical diagnostic causes, unconditional production language, and ambiguous online
effect interpretation. It proposed explicit estimands, paired useful-margin rules,
multiplicity handling, and clearer treatment of training-procedure variation.

Expected dissent: other members might prefer a simpler taxonomy or treat domain wording
as practical shorthand.

## Computer Vision Evaluation Reviewer

The reviewer found missing open-set detection semantics, underdefined document-structure
matching, weak deployment eligibility requirements, and incomplete evaluator boundary
fixtures. It requested task-specific matching contracts, golden fixtures, and stronger
resource and fallback evidence.

Expected dissent: other members might classify fixtures as implementation hardening
rather than a validity requirement.

## Representation Learning Reviewer

The reviewer found that representation routing could bypass common foundations,
clustering lacked an executable protocol, rare operating points lacked support rules,
broad claims needed stronger breadth, and contamination status needed explicit handling.

Expected dissent: a narrow claim may legitimately rely on one protocol and one dataset.

## Skill Architecture Reviewer

The reviewer identified contradictory mandatory versus conditional routing, a large
diagnostic catalogue, fragile cross-skill internal paths, and a report contract that
required economics for non-economic work. It proposed one universal core route,
conditional add-ons, portable handoffs, and report profiles.

Expected dissent: file length alone is not a correctness defect, and excessive splitting
can create more routing overhead than it removes.
