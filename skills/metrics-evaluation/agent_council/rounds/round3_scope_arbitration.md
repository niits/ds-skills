# Round 3: Scope Arbitration

The chair accepted eight focused edits:

1. Make the evaluation protocol universal and every other file conditional.
2. Add separate paired conclusions against zero and a useful margin.
3. Correct prevalence-based AUC claims.
4. Replace asserted diagnoses with hypotheses and discriminating checks.
5. Add conditional report profiles and a computer-vision evidence gate.
6. Complete structured-output boundaries, OCR structure matching, and open-set detection semantics.
7. Add representation clustering, rare-operating-point support, breadth, and contamination status.
8. Remove fragile paths into another skill's internal layout.

## Initial Deferrals

The chair initially deferred splitting the large diagnostic file because decomposition
could add routing complexity. It also deferred algorithm surveys and domain-specific
confidence-interval recipes.

## Dissent

- The statistical role preferred formal equivalence and non-inferiority terminology.
- The vision role wanted a larger fixture catalogue.
- The production perspective wanted economics for every deployment-facing claim.
- The maintainer perspective opposed splitting diagnostics without an explicit user requirement.

The later user requirement to refactor by domain and topic reopened the structural decision.
